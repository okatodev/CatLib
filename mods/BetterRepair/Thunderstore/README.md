# Better Repair

More cardboard for the repair table, or as much as you want.

In the game the repair table holds three sheets of cardboard. Every repair of a damaged parcel takes one,
and a new day brings all three back. Better Repair lets you change that.

## What you can change

- **Unlimited cardboard.** The table never runs out.
- **Stock.** How many sheets the table holds, from 1 to 99. It still shows three at a time, the rest waits underneath.
- **New day brings.** The full stock like in the game, or a set number of sheets per day for a tighter game.
- **Cardboard messages.** A short note after a repair with how much is left, and in the morning with how much came.

Out of the box everything is as in the game: three sheets, all back every morning.
The cardboard you have left is kept with your save. Remove the mod and the save is just as before.

## Settings

Settings → Mods → Better Repair.

## Playing with friends

Everyone in the game needs Better Repair, and the host's settings are the ones that count.
If someone joins without it, the table works as in the game until that player leaves.

## Found a bug?

Report it on [GitHub](https://github.com/okatodev/CatLib/issues). If the game crashed, attach the folder from the CatLib crash window,
otherwise `BepInEx/LogOutput.log` before you start the game again.
